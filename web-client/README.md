# SmartRuble Web

Next.js App Router + TypeScript. Клиент текущего B2B API SmartRuble.

## Запуск

В корне монорепозитория поднимите backend через Docker Compose. Если web-client уже запущен в Compose, остановите его перед локальным npm run dev, чтобы освободить порт 3000.
Затем в этой папке выполните:

```sh
cp .env.example .env.local
npm ci
npm run dev
```

Откройте http://localhost:3000. Войдите по телефону и паролю пользователя auth-service.
Демонстрационные роли и пароли описаны в docs/MVP_GUIDE.md.

GATEWAY_URL задаёт адрес шлюза для процесса Next.js, по умолчанию http://localhost:8080.
Браузер обращается к /api/v1 на собственном origin. Next.js перенаправляет запросы в gateway.
Внутри контейнера localhost обозначает этот контейнер. Используйте адрес шлюза в общей Docker-сети.

## Возможности

- Вход, выход, обновление access-токена с сериализацией refresh-запросов.
- Реестр контрагентов с поиском, фильтрами и серверной пагинацией.
- Создание и редактирование реквизитов с обработкой ошибок валидации.
- Карточка, банковские счета, выбор основного и отключение счёта.
- Изменение статуса, обязательная причина для SUSPICIOUS/BLOCKED, история решений.
- Кнопки действий учитывают роли. Авторизацию операций выполняет backend.

Токены хранятся в памяти вкладки. Перезагрузка страницы требует нового входа.
Это осознанное ограничение первой версии. Пароли и токены не записываются в localStorage.
Рабочие экраны распоряжений, смет, платежей, согласований, финансового обзора и Kafka-уведомлений реализованы в app/workbench.tsx. ML-оценки отсутствуют.

## Структура

app/page.tsx — экран входа, реестр и диалоги.
lib/api.ts — DTO, HTTP-клиент и жизненный цикл сессии.
app/globals.css — адаптивный интерфейс.
next.config.ts — проксирование запросов к gateway.

Проверки: npm test, npm run typecheck и npm run build.
Тесты проверяют ротацию JWT при запоздалом 401, истечение сессии, ошибки валидации и выход.
Production: npm run build, затем npm start. Изменение GATEWAY_URL требует новой сборки, поскольку rewrite формируется при сборке.

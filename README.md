# SmartRuble — контроль расходов подрядчиков

Локальный демонстрационный MVP B2B-системы: компания утверждает смету, подрядчик создаёт заявку, правила проверяют получателя и доступный бюджет, финансовый директор согласует исключения, банковский mock проводит платёж. История решений и журнал событий доступны в веб-интерфейсе.

**Границы:** одна компания-заказчик, рублёвые суммы в PostgreSQL, эмулятор банка. Реального подключения к платформе цифрового рубля, ФНС, ГИС ЖКХ и смарт-контрактам нет. Проверка контрольной суммы ИНН не подтверждает существование компании.

## Быстрый запуск

Нужен запущенный Docker Desktop / Docker Engine с Compose v2. Первый запуск скачивает образы и зависимости.

```sh
# Из корня репозитория; существующий .env не перезаписываем
[ -f .env ] || cp .env.example .env
./demo/compose.sh up --build -d
./demo/compose.sh run --rm demo-tools seed
```

Если seed запущен до готовности Java-сервисов, подождите их запуска и повторите команду. Повтор не обнуляет платежи и бюджеты. Стенд использует отдельный Compose project `smartruble-mvp` и свои volumes.

- Веб-интерфейс: http://localhost:3000
- Swagger: http://localhost:8080/swagger-ui.html
- Менеджер: `+70000000001`, финансовый директор: `+70000000002`, подрядчик: `+70000000003`, сотрудник: `+70000000004`.
- Пароль **только локальных демопользователей**: `Demo12345!`.

```sh
# Сквозной тест, создаёт вымышленные заявки и меняет mock-баланс
./demo/compose.sh run --rm demo-tools smoke
# Остановить стенд с сохранением данных
./demo/compose.sh down
```

## Реализовано

| Компонент | Состояние |
|---|---|
| api-gateway | JWT, очистка входящих X-User-* заголовков, маршрутизация, rate limit, circuit breaker |
| auth-service | Вход, регистрация, роли, JWT, ротация refresh-токенов |
| billing-service | Контрагенты, сметы и бюджеты, заявки, согласование, резервирование, история, outbox, обзор |
| abs-service | Постоянный mock-баланс, идемпотентный перевод, воспроизведение отказа/потери ответа |
| notification-service | Kafka consumer, дедупликация, повторная доставка, DLT, журнал для финансового директора |
| web-client | Next.js / TypeScript: рабочие экраны всего демосценария |
| android-client | Kotlin / Compose шаблон; полная сборка и эмулятор требуют установленного Android SDK |
| integration-service | Внешние интеграции отложены; в демонстрационном контуре отсутствует |

У сервисов собственные базы PostgreSQL. Модули внутри billing используют одну billing_db и локальные транзакции. Внешние зависимости — HTTP и Kafka. В Compose внутренние сервисы не публикуют порты; web, gateway и две БД для pgAdmin привязаны к loopback.
